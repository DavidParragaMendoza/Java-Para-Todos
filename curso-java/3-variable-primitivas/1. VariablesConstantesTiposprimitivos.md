# 📌Teoría - Variables y Constantes

### **1. Las Variables**

- **Definición:** Son espacios físicos de memoria reservados para almacenar un valor específico que puede ser modificado a lo largo del tiempo durante la ejecución del programa.
- **Tipado Fuerte:** Java es un lenguaje **fuertemente tipado**. Esto significa que estás obligado a definir explícitamente qué tipo de dato se almacenará en cada variable para que el sistema reserve el espacio necesario en memoria. No puedes guardar un carácter o un decimal en una variable declarada para enteros.
- **Sintaxis de Declaración:**
    
    ```
    tipo_de_dato nombreVariable;
    ```
    
    - *Ejemplo:* `int edad;` (Declara una variable para números enteros. Si no se inicializa, tiene un valor por defecto de `0`).

---

### **2. Las Constantes**

- **Definición:** Al igual que las variables, son espacios de memoria para almacenar datos, pero con la diferencia de que **su valor no puede ser modificado** una vez asignado.
- **Sintaxis de Declaración:** Se utiliza obligatoriamente la palabra reservada **`final`** delante del tipo de dato.
    
    ```
    final tipo_de_dato NOMBRE_CONSTANTE = valor;
    ```
    
    - *Ejemplo:* `final int MAX_USERS = 42;`
- **Diferencia Crítica de Inicialización:**
    - A diferencia de las variables, **las constantes no tienen valores por defecto**.
    - **Tiempos de asignación:** Puedes definir el valor de una constante en *tiempo de compilación* (cuando escribes el código) o en *tiempo de ejecución* (cuando el programa corre y recibe el dato por primera vez). En ningún caso se podrá modificar el dato una vez que haya sido asignado.

---

### **3. Reglas de Nomenclatura (Identificadores)**

Al nombrar variables y constantes, existen normas de cumplimiento obligatorio y buenas prácticas de la industria:

| Tipo de Regla | Norma / Recomendación | Ejemplo Correcto | Ejemplo Incorrecto |
| --- | --- | --- | --- |
| **Obligatoria** | **Sin espacios:** No pueden contener espacios en blanco. | `nombreCompleto` | `nombre completo` |
| **Obligatoria** | **Inicio del nombre:** Deben empezar obligatoriamente con una letra, signo de pesos (`$`) o guion bajo (`_`). Nunca con números. | `_usuario`, `$saldo`, `edad2` | `2edad` |
| **Obligatoria** | **Caracteres permitidos:** Solo letras, números, `$` y `_`. | `codigo_1` | `codigo-1` (guion medio) |
| **Obligatoria** | **Palabras reservadas:** No pueden llamarse igual que términos propios del lenguaje (como `if`, `int`, `class`). | `miClase` | `class` |
| **Práctica Recomendada** | **CamelCase (Variables):** La primera letra en minúscula y las palabras compuestas inician con mayúscula. | `nombreUsuario` | `nombreusuario` |
| **Práctica Recomendada** | **UpperCase (Constantes):** Todo en mayúsculas y palabras separadas con guion bajo. | `PRECIO_MAXIMO` | `precioMaximo` |
| **Práctica Recomendada** | **Nombres Significativos:** Evitar abreviaciones confusas que no expliquen el contenido. | `sueldoMensual` | `sm` |

> ⚠️ **Nota de Sensibilidad (Case-sensitive):** Java distingue estrictamente entre mayúsculas y minúsculas. Las variables `USER` y `user` son tratadas como dos variables distintas en memoria, lo que puede provocar graves errores lógicos si se confunden.

# 📌Teoría - Tipos de Datos Primitivos

### **1. ¿Qué es un Dato Primitivo?**

Son tipos de datos básicos provistos por el lenguaje que **contienen un solo valor** a la vez en memoria (a diferencia de los datos de referencia que apuntan a objetos o direcciones de memoria complejas).

### **2. Clasificación y Capacidades de Almacenamiento**

Java cuenta con **8 tipos de datos primitivos** divididos en 4 familias:

| Familia | Tipo de Dato | Tamaño en Memoria | Valor por Defecto | Rango / Uso Común |
| --- | --- | --- | --- | --- |
| **Enteros** | `byte` | 1 byte (8 bits) | `0` | -128 a 127. Útil para ahorrar memoria en arreglos grandes. |
|  | `short` | 2 bytes (16 bits) | `0` | -32,768 a 32,767. Duplica al `byte`. |
|  | `int` | 4 bytes (32 bits) | `0` | Enteros de uso general estándar. |
|  | `long` | 8 bytes (64 bits) | `0L` | Enteros extremadamente grandes. Requiere terminar el valor con la letra **`L`** o **`l`** (ej: `9223372036854775807L`). |
| **Decimales** | `float` | 4 bytes (32 bits) | `0.0f` | Números con decimales de precisión simple. Requiere la letra **`f`** o **`F`** al final (ej: `3.14f`). |
| (Reales) | `double` | 8 bytes (64 bits) | `0.0d` | Números con decimales de precisión doble. **Es el tipo decimal por defecto en Java**. |
| **Caracteres** | `char` | 2 bytes (16 bits) | `\u0000` | Almacena un solo carácter (letra, símbolo o número) bajo el estándar **Unicode**. Se define con comillas simples (ej. `'A'`, `'@'`, `'\u0021'`). |
| **Lógicos** | `boolean` | 1 bit (teórico) | `false` | Solo admite **`true`** o **`false`**. Internamente es `1` o `0`. |

### **💡 Notas Clave de Datos Primitivos:**

- **Literales Decimales:** Como Java interpreta por defecto cualquier número con punto decimal como un `double`, si declaras un `float` sin la letra `f` al final (ej. `float peso = 72.5;`), el compilador arrojará un error.
- **El tipo `char` no es matemático:** Si guardas un número como carácter (ej: `char numero = '1';`), se guarda la representación visual del símbolo, por lo que no podrás realizar operaciones matemáticas con él.
- **Variables booleanas:** Una buena práctica de código limpio para las variables lógicas es nombrarlas usando prefijos de pregunta como `is` o `has` (ej: `isLoading`, `isActive`).
