# 📌 Fundamentos - Control de flujo

Los **flujos de control** en Java definen de manera lógica cómo se ejecutan las instrucciones, los algoritmos y los procesos de un programa. En lugar de ser un camino lineal e invariable, el flujo de control permite que la aplicación tome decisiones dinámicas basándose en condiciones.

La estructura de control de Java se divide en **tres grandes categorías**:

---

### **1. Flujo Secuencial**

- **Definición:** Es la categoría más básica y conocida, que se utiliza al comenzar a programar. Las instrucciones se ejecutan de manera estrictamente lineal, es decir, **en el orden físico en el que aparecen escritas** en el código.
- **Características:**
    - No existen desvíos, bifurcaciones ni saltos adicionales de líneas.
    - *Ejemplo práctico:* Declarar una variable, asignarle un dato y mostrarla inmediatamente en consola con un `System.out.println`. Las líneas se procesan de arriba hacia abajo sin omitir ninguna.


---

### **2. Flujo Condicional (Toma de Decisiones)**

- **Definición:** Permite que el programa tome caminos o decisiones autónomas basándose en la evaluación de una **condición**.
- **Características:**
    - Al llegar a un punto del programa donde hay una evaluación condicional, el sistema decidirá si toma un camino u otro.
    - **Exclusividad de caminos:** Si se toma un camino, el otro queda totalmente descartado, provocando un "salto" en el flujo normal. Esto significa que habrá líneas de código en tu aplicación que a veces se ejecutarán y otras no, dependiendo de si la condición es verdadera o falsa.
    - **Estructuras asociadas en Java:** Las instrucciones condicionales nativas son **`if`** y **`switch`**. Ambas evalúan una condición booleana (verdadero o falso) para decidir si acceden al bloque de código interno o si lo omiten. Si no se cumple ninguna de las condiciones deseadas, el flujo puede caer en una opción por defecto (un bloque `else` o un caso `default`).

---

### **3. Flujo Repetitivo (Bucles o Ciclos)**

- **Definición:** Consiste en la ejecución repetitiva de un bloque específico de instrucciones **mientras una condición determinada se evalúe como verdadera (`true`)**.
- **Características:**
    - **Condición de ingreso y egreso:** Para acceder al bucle por primera vez, la condición debe ser obligatoriamente verdadera. Para lograr salir de este ciclo y continuar con el resto del programa, la condición debe transformarse en falsa (`false`).
    - **El peligro del Bucle Infinito:** Si la condición se mantiene verdadera para siempre y no hay ninguna instrucción interna que la modifique, el programa quedará atrapado ejecutando el bucle infinitamente, lo que colapsará el sistema.
    - **El Contador como Control de Ciclos:** Tomando como ejemplo el bucle **`for`**, este requiere de tres partes esenciales para funcionar de manera segura:
        1. **Inicialización:** Declaración de la variable de control (por ejemplo, `int i = 1;`).
        2. **Condición:** La evaluación lógica de permanencia (por ejemplo, `i <= 5`).
        3. **Contador/Acumulador (Incremento/Decremento):** Por ejemplo, un operador unario de post-incremento `i++`. El propósito crucial de este incremento es actuar como el **"acercamiento a la condición de corte"**. Con cada vuelta del ciclo, la variable de control se acerca un paso más a hacer falsa la condición para romper el bucle con éxito y finalizar adecuadamente.
